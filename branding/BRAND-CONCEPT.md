# 铁风执刃品牌规范 v1

## 正式名称

- 中文：**铁风执刃**
- 英文：**Ironwind: Hands-On Combat**
- 中文说明：**Kenshi 自由操控与方向攻防**
- 英文说明：**Hands-On Directional Combat for Kenshi**
- 内部技术 ID：继续使用 `IronwindCombat`

“铁风”保留已有识别资产；“执刃”表达玩家亲手掌握武器和战斗时机。`Hands-On Combat` 同时覆盖 WASD 直接控制、方向攻防和越肩／第一人称临场感，比只写 `Directional Combat` 更接近完整功能。

## 视觉识别

- 主体：近距离越肩战斗人物。
- 核心符号：准星周围四个统一细箭头，其中一个绿色，表示当前可用攻击方向。
- 命中反馈：准星附近的断开半透明红色 X。
- 敌人状态：目标头顶显示小而精确的两行血条；上层为细长主生命，下层为更小的肢体状态色条，不显示文字和数字。
- 色彩：炭黑、氧化铁、沙骨色；绿色只作功能强调，红色只作命中强调。
- 构图：256 px 缩略图仍要看清“人物＋四向输入＋命中”；上方保留标题区。
- 禁止：魔法光效、通用中古奇幻、官方 Kenshi Logo、复制游戏角色、用大量 UI 遮挡画面。
