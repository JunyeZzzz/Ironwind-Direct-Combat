# 铁风执刃｜Ironwind: Hands-On Combat

> 把 Kenshi 的战斗从“下达命令”变成“亲手交锋”。

铁风执刃是一款面向 Kenshi 的自由操控战斗 Mod。按下 `V`，你将直接接管当前角色：用 WASD 移动，以越肩或第一人称视角观察战场，通过鼠标选择攻击与格挡方向，并在近距离用 `E` 调用原版交互菜单。

它不是一套脱离 Kenshi 的新伤害系统，也不会偷偷替玩家自动追击或连击。你的输入负责决定**何时行动、向哪个方向出手**；武器范围、可用招式、技能、命中、格挡、闪避、护甲、伤害、受击反应和经验仍由 Kenshi 原版战斗链决定。

## 核心特色

### 直接操控

- `V` 一键进入或退出直接控制。
- `W/A/S/D` 按镜头方向移动当前角色，松键即停。
- 支持越肩视角与第一人称视角，并保留室内镜头缩短、墙体避让和菜单光标交接。
- V 模式下声音监听位置跟随受控角色，而不是留在远处的视觉镜头位置。
- Z/X 继续是 Kenshi 原版 1×／5×速度键；铁风不会占用它们。

### 四向攻击

- 按住左键并移动鼠标选择上、下、左、右攻击方向，松开后出手。
- 当前选择以准星周围的向心箭头显示：绿色表示原版当前确实提供该方向招式，白色表示尚未确认或没有对应招式。
- 玩家始终可以对空气挥刀；准星目标只决定攻击意图，不赋予额外命中距离。
- 挥刀途中可缓存一次下一击，但每次输入只授权一刀，不会交给 AI 自动连击。
- 空手武术也会查询原版招式条件，不会凭空补出角色尚未解锁的动作。

### 手动或自动选向格挡

- 手动模式：移动鼠标选择方向并按住右键；方向匹配且来袭位于可防御前方时，立即交给原版武器格挡结果。
- 自动模式：玩家仍需按住右键表达防御意图，但具体方向由 Kenshi 原版 AI 选择；原版没有选出有效防御时就会正常挨打。
- 没有额外“完美格挡”时间窗、必成功奖励或蓝色增益光。火花、声音和格挡经验仍由原版处理。
- 格挡期间暂停 WASD 位移，避免移动层破坏防御姿势；松开右键立即恢复控制。

### 尊重原版的近战结算

- 敌对目标使用原版 `STARTUP → CHOP_WEAPON` 攻击状态和攻击区。
- 武器长度、实际刀路、招式、攻防技能、格挡、闪避、护甲、伤害和 XP 全部继续生效。
- 铁风不会用固定扇形强制命中敌人，不会把“看起来很近”直接等同于伤害，也不会手工补伤害。
- 攻击中立角色时，只有权威受击链确认真实命中才提交敌对事件；挥空、被格挡或被闪避不会提前挑衅。
- 断腿爬行、装死及仍有意识的倒地目标可进入原版攻击链；真正昏迷或死亡目标会被排除。
- 玩家队伍成员在目标选择与命中阶段都有保护，不会成为铁风攻击的有效受害者。

### 原版受击与动作完整性

- 受到重击时，移动、攻击与格挡输入会一直锁到原版 `STUMBLE/REACTION_BLOCK` 状态自然结束。
- 轻受击不会被铁风人为延长，重僵直也不会被固定毫秒数提前取消。
- 命中与落空使用同一原版挥刀时间轴；动作不会因为没造成伤害就故意截成半刀。
- 攻击命中阶段结束后可转入格挡，但不会让攻击与格挡同时抢占同一动画层。

### 战斗信息与反馈

- 当前焦点目标显示姓名和紧凑的两行八部位生命面板：血、头、胸、腹、双臂和双腿。
- 面板复用 Kenshi 原版医疗颜色与分段：有机健康、骨人／机械部位、钝伤、切割伤、包扎、夹板和机械磨损均按真实状态显示。
- 原版受害者确认真实受击后，准星附近显示短暂的半透明红色断开 X；挥空、格挡或闪避不会产生假命中提示。
- 敌人攻击不会叠加铁风自制的手部／武器闪光；自动格挡仍在内部读取原版来袭事件。武器接触时的原版格挡火花、声音和经验保持不变。
- 白色、黄色和绿色准星分别区分普通／敌对视线、中立与友方交互语义。

### 近距交互

- 准星靠近可交互人物、门或设施时，目标上会出现跟随位置的黄色 `E`。
- 按 `E` 临时暂停并打开该对象的原版上下文菜单；选完恢复时间，没有额外常驻交互模式。
- 右键无论按多久都只承担格挡，不再因为长按误弹交互框。
- 暂停、菜单、库存、对话和地图都会正常释放鼠标；恢复后重新接管 V 模式视角。

## 默认操作

| 输入 | 功能 |
| --- | --- |
| `V` | 开启／关闭铁风直接控制 |
| `W/A/S/D` | 按镜头方向移动 |
| 按住左键＋移动鼠标 | 选择攻击方向 |
| 松开左键 | 提交一刀 |
| 按住右键 | 手动方向格挡，或授权原版 AI 自动选向 |
| 选向时按右键 | 取消尚未提交的攻击 |
| `E` | 暂停并打开近距目标的原版交互菜单 |
| `F` | 越肩／第一人称切换 |
| 鼠标滚轮 | 调整越肩距离；最近端进入第一人称 |
| `Z`／`X` | Kenshi 原版 1×／5×游戏速度 |
| `Tab` | 打开库存并释放鼠标，保留 V 模式状态 |

按键和常用参数可在“选项 > 铁风执刃”中调整；兼容性与特殊种族校准项仍可在 INI 中修改。

## 适合什么玩家

如果你喜欢 Kenshi 的技能、装备、受伤与世界后果，但希望移动、出刀方向、防御意图和镜头由自己掌握，铁风执刃就是为这种玩法设计的。它追求的是“玩家控制时机，Kenshi 决定结果”，而不是把 Kenshi 变成另一套动作游戏。

## 要求与安装

- Kenshi 1.0.65，64 位。
- RE_Kenshi 0.3.5。
- 将完整 `IronwindCombat` 文件夹放入 `Kenshi/mods/`。
- 启动器中只启用 `IronwindCombat.mod`。
- 不要同时启用原 `WASDCombatPlugin.mod`，两者会重复加载同名兼容 DLL 与 Hook。

## 当前边界

- 当前版本聚焦近战；手持弩尚未纳入铁风控制体系，继续按原版处理。
- 玩家主动闪避系统尚未提供。旧的计时翻滚实现已经删除；敌人的原版闪避与自动防御中原版选择的 dodge 不受影响。
- 按住左键目前只选择方向，没有额外人物蓄势姿势。
- 人物、门和可用设施有近距候选；地面物品只在 Kenshi 自己精确识别时提示，不做全场物品扫描。
- 第一人称角色隐藏使用材质脚本，可能与替换同一角色 shader 的 Mod 发生加载顺序冲突。
- 与其他直接控制或战斗任务 Mod 同用时，对方应通过铁风提供的只读控制权接口处理自己的任务恢复。
