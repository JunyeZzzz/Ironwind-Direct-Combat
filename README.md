铁风执刃是由 **cjy233** 维护、面向 Kenshi 1.0.65 与 RE_Kenshi 0.3.5 的自由控制战斗 Mod。当前项目、发布包和维护流程均以“铁风执刃 / Ironwind: Hands-On Combat”为正式身份。
